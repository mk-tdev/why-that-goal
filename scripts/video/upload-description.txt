Microsoft Foundry powers three specialized roles: match analysis, storytelling and evidence review. A typed TypeScript coordinator records shared snapshots, fact lookups, handoffs and bounded corrections. Azure Container Apps hosts the app with managed-identity inference. This is custom orchestration, not Microsoft Agent Framework.
